# 세종대학교 1~3차년도 개발 항목 통합 정리

정리 기준: 1·2·3차년도 제안서와 연차보고서. 후속 차년도에서 발전·대체된 항목은 최신 구현만 남기고, 대체되지 않은 기존 기능은 유지했습니다.
각 항목의 구현 위치와 실행 방법은 해당 폴더의 README에 있습니다.

## 1. 계층형 연합학습 시뮬레이터 (`hierarchical_fl`)

- (1차) 연합 학습 시험용 파이썬 환경 기반 단일 컴퓨터 시뮬레이션 환경 설계
- (2차) Flask 기반의 연합 학습 시험용 멀티 컴퓨팅 시뮬레이션 환경 구현
- (3차) Flask 기반의 계층적 연합 학습 시험용 컴퓨팅 시뮬레이션 환경 구현

통합 결과
- 3차 계층 구조(클라이언트–Flask 엣지 서버–중앙 서버, REST 통신, 게임 이론 매칭)를 최종 구현으로 하고 1·2차 기능을 그 안의 실행 방식으로 통합
  ‣ 1차 단일 컴퓨터 실행: 한 프로세스 안에서 Flask REST 경로를 그대로 실행(`transport=local`), 클라이언트 학습 스레드 병렬화(`client-workers`), 엣지 프로세스 병렬화(`--spawn-edges`), asyncio 비동기 엣지 통신
  ‣ 2차 멀티 컴퓨팅: 엣지 서버를 별도 컴퓨터에서 실행(`--edges URL,...`), SQLite DB 래퍼, 데이터 비율·정보 엔트로피 산출 API, 전역 모델 모니터링·R/H 히트맵 대시보드
  ‣ 3차 계층형: 효용 함수(기대 보상 − 데이터·통신 비용), EMA 품질 추정량, 우선순위 기반 안정 매칭, 엣지 계층 HierFAVG 집계, 계층 트리·우선순위·통신 상태·매칭 행렬 시각화, FedAvg/FedProx/q-FedAvg 등 Flower 전략 선택
- 대체: 2차 단일 서버 구조는 엣지 1개 설정으로 표현되므로 별도 실행기를 두지 않음

## 2. 보안 공격·방어 시뮬레이션 모듈 (`security_sim`)

- (1차) 보안 시뮬레이션 시험 환경 및 네트워크 비용 산출 환경의 설계
- (2차) 다계층적 구조의 보안 시험 시뮬레이션 환경
- (3차) 보안 시뮬레이션 환경 고도화

통합 결과
- 공격과 방어는 연차별로 대상이 달라 서로 대체하지 않고 모두 유지
  ‣ 1차: 데이터 조작 공격 ↔ 데이터 분포 분석, 모델 변조 공격 ↔ 파라미터 통계 이상 탐지, 가짜 클라이언트(중앙 서버) 공격 ↔ 인증서 검증, 시나리오별 네트워크 비용 산출
  ‣ 2차: 데이터 중계 공격 ↔ HMAC-SHA256 무결성 검증, 계층적 협력 공격 ↔ K-Means 담합 탐지, 다단계 피싱 ↔ 2차 인증·실시간 모니터링, One-Class SVM 이상치 탐지, 엣지·전역 2계층 방어
  ‣ 3차: 내부자 협력 공격(적응형 포함) ↔ 내부자 활동 모니터링·로그 분석, 모델 역추적 공격(API 질의 기반 모델 추출·입력 복원) ↔ 출력 제한·출력 노이즈(차분 프라이버시)·질의 한도
- 단일 서버(KIST 시스템 포함)와 계층형 시뮬레이터 모두에 같은 플러그인으로 적용

## 3. 연합학습 시나리오 테스트 모듈 (`scenario_test`)

- (3차) 시뮬레이션 환경에서의 다양한 연합 학습 시나리오 테스트

통합 결과
- 제안서의 네트워크 지연, 클라이언트 참여 비율 변동, 데이터 불균형 시나리오에 엣지 서버 장애, 내부자 협력 공격 시나리오를 추가
- 기준 환경 대비 적응력 지수, 지연에 따른 업데이트 주기, 참여 변화에 따른 수렴, 클라이언트별 성능과 기여도 분석

## 4. 연산 그래프 기반 모델 가지치기 모듈 (`graph_pruning`)

- (1차) AI 모형 소규모화 기술 설계
- (2차) 고도화된 AI 모형 소규모화 기술 구현
- (3차) 연산 그래프 기반 가지치기를 활용한 AI 모형 소규모화 기술 고도화

통합 결과
- 최종: 연산 그래프 생성 → 노드·엣지 경로 중요도 → 임계값 가지치기 → 손실 변화 기반 임계값 동적 조정, 연합학습 중 전역 모델 가지치기
- 유지: 2차 BN 스케일 L1 구조적 희소성(로컬 학습 정규화), 기울기 기반(테일러) 중요도 선택 옵션, 1차 가중치 절댓값 기준 균일 필터 가지치기(비교 기준)
- 대체: 1·2차 임계값 고정/학습 기반 조정은 3차 동적 조정으로 대체

## 5. 중간층 매칭 기반 지식 증류 모듈 (`layer_kd`)

- (1차) 지식 증류 기술 설계
- (2차) 중간 레이어 매칭 기술을 활용한 지식 증류 기술 구현
- (3차) 고도화된 중간층 매칭 기술을 적용한 지식 증류 기술

통합 결과
- 최종: 로짓 증류 + 가중 특징맵 매칭 + 어텐션 맵 매칭(손실·이득) + GAN 기반 중간층 매칭을 결합한 증류(`combined`), 상위 계층 교사 → 하위 계층 학생 연합 증류
- 유지: 1차 소프트 라벨 혼합 손실과 다중 교사 앙상블, 2차 레이어 중요도 가중 매칭과 중요도 기반 적응형 학습률(각각 단독 방법으로도 선택 가능)

## 6. 데이터 불균형 해결 모듈 (`data_imbalance`)

- (1차) 데이터 불균형 문제 해결 기술 설계

통합 결과
- 설계 항목을 구현: 클라이언트별 SMOTE·Tomek Links·ENN 조합 샘플링, 데이터 양과 로컬 손실 기반 동적 가중치 집계, 적용 전후 로컬/전역 성능 비교

## 7. 다계층 네트워크 비용 최적화 모듈 (`network_cost`)

- (2차) 다계층 네트워크 비용에 따른 최적화 기술 시뮬레이션 설계 및 구현

통합 결과
- 엣지 컴퓨팅(로컬 노드 업데이트 경량화), LRU 캐시(중복 전송 방지), DAG 비용 최적 경로를 실제 Flower 메시지 전송에 적용하고 최적화 전후 라운드별 전송량·비용 비교
- 1차 보안 시나리오의 네트워크 비용 산출은 보안 모듈의 라운드별 비용 기록으로 유지
